# แหล่งข้อมูลและการตรวจสอบความถูกต้อง — PS Locator

เอกสารนี้อธิบายที่มาของข้อมูลทุกฟิลด์ในฐานข้อมูล เพื่อให้พนักงานสอบสวนตรวจสอบย้อนกลับได้

## 1. แหล่งที่มาหลัก (Primary source)

**สำนักงานตำรวจแห่งชาติ (Royal Thai Police)**

- หน้าทางการ: https://www.royalthaipolice.go.th/th/police-stations
- หน้านั้นฝัง (iframe) ระบบ “ข้อมูลสถานีตำรวจ” ของ ตร. ไว้
- ระบบเดียวกันถูกเรียกผ่าน API ภายใน 2 เส้นทาง:
  - `…/stations/index.php?action=fetch_state&country_id=<id จังหวัด>` → รายชื่อสถานีในจังหวัด
  - `…/stations/index.php?action=fetch_city&state_id=<id สถานี>` → รายละเอียดสถานี
- ฟิลด์ที่ดึง: ชื่อสถานี · ที่อยู่ · เบอร์โทรศัพท์ · เบอร์โทรสาร · เว็บไซต์ทางการ
- วันที่เข้าถึงข้อมูล: **16 พฤศจิกายน 2569**

### ทำไมเชื่อถือได้

- เป็นฐานข้อมูลเดียวกับที่ สำนักงานตำรวจแห่งชาติ ใช้ประกาศ “ข้อมูลสถานีตำรวจทั่วประเทศ” ให้ประชาชนและหน่วยงานรัฐ
- ข้อมูลแต่ละรายการถูกดึงแบบ 1:1 ไม่ผ่านการแต่งเติม/แปลภาษา
- ฟิลด์ที่ต้นทางว่างไว้ ระบบแสดง “ไม่มีข้อมูล” แทนการสุ่มใส่

## 2. การผูก “ภาค” (กองบัญชาการ)

ภาคของแต่ละจังหวัดผูกตาม **การแบ่งเขตพื้นที่การปกครองของสำนักงานตำรวจแห่งชาติ**
(กองบัญชาการตำรวจนครบาล + กองบัญชาการตำรวจภูธรภาค 1–9) อ้างอิงจากประกาศกำหนดหน่วยงานและเขตอำนาจการรับผิดชอบของ ตร. และสารบัญ “ท้องที่ตำรวจ” (th.wikipedia.org ซึ่งอ้างอิงประกาศ ตร.)

| ภาค | ศูนย์บัญชาการ | จังหวัดที่รับผิดชอบ |
|---|---|---|
| บช.น. | กรุงเทพมหานคร | กรุงเทพมหานคร |
| ภ.1 | นนทบุรี | ชัยนาท นนทบุรี ปทุมธานี พระนครศรีอยุธยา ลพบุรี สมุทรปราการ สระบุรี สิงห์บุรี อ่างทอง |
| ภ.2 | ชลบุรี | จันทบุรี ฉะเชิงเทรา ชลบุรี ตราด นครนายก ปราจีนบุรี ระยอง สระแก้ว |
| ภ.3 | นครราชสีมา | ชัยภูมิ นครราชสีมา บุรีรัมย์ ยโสธร ศรีสะเกษ สุรินทร์ อำนาจเจริญ อุบลราชธานี |
| ภ.4 | ขอนแก่น | กาฬสินธุ์ ขอนแก่น นครพนม บึงกาฬ มหาสารคาม มุกดาหาร ร้อยเอ็ด เลย สกลนคร หนองคาย หนองบัวลำภู อุดรธานี |
| ภ.5 | เชียงใหม่ | เชียงราย เชียงใหม่ น่าน พะเยา แพร่ แม่ฮ่องสอน ลำปาง ลำพูน |
| ภ.6 | พิษณุโลก | กำแพงเพชร ตาก นครสวรรค์ พิจิตร พิษณุโลก เพชรบูรณ์ สุโขทัย อุตรดิตถ์ อุทัยธานี |
| ภ.7 | นครปฐม | กาญจนบุรี นครปฐม ประจวบคีรีขันธ์ เพชรบุรี ราชบุรี สมุทรสงคราม สมุทรสาคร สุพรรณบุรี |
| ภ.8 | ภูเก็ต | กระบี่ ชุมพร นครศรีธรรมราช พังงา ภูเก็ต ระนอง สุราษฎร์ธานี |
| ภ.9 | สงขลา | ตรัง นราธิวาส ปัตตานี พัทลุง ยะลา สงขลา สตูล |

## 3. ระดับความน่าเชื่อถือของแต่ละรายการ

| ระดับ | ความหมาย | ป้ายในเว็บ |
|---|---|---|
| ยืนยันจากต้นทาง (verified) | ดึงจากระบบเปิดเผยข้อมูลของ ตร. โดยตรง ณ วันที่ระบุ | ✓ ยืนยัน |
| รอตรวจสอบ (pending) | รวบรวมจากแหล่งเปิดอื่น (เช่น OpenStreetMap) ยังไม่ผ่านการยืนยันกับ ตร. | ⚠ รอตรวจสอบ |

> เวอร์ชันแรกของเว็บไซต์เผยแพร่เฉพาะรายการที่ **ยืนยันจากต้นทาง** เท่านั้น รายการจากแหล่งอื่นจะถูกเพิ่มในเฟสถัดไปพร้อมป้าย “รอตรวจสอบ” เสมอ

## 4. ข้อจำกัดและข้อควรระวัง

- ที่อยู่บนเว็บทางการใช้รูปแบบย่อ เช่น “ม.1 ต.คลองยาง” — ระบบไม่แต่งเติมชื่อเต็ม
- เบอร์โทรศัพท์บางสถานีซ้ำกับเบอร์แฟกซ์ ตามที่ต้นทางกรอกไว้
- สถานีที่ต้นทางไม่กรอกข้อมูล แสดง “ไม่มีข้อมูล” อย่าใช้แทนที่อยู่ที่คาดเดา
- การนำทาง Maps ใช้ชื่อสถานี + ที่อยู่ในการค้นหา อาจคลาดเคลื่อนหากที่อยู่กำกวม ควรยืนยันจุดหมายก่อนเดินทาง

## 5. ขั้นตอนตรวจสอบย้อนกลับ (สำหรับเจ้าหน้าที่)

1. เปิด https://www.royalthaipolice.go.th/th/police-stations
2. เลือกจังหวัดเดียวกับรายการที่สงสัย
3. เลือกสถานี → เทียบที่อยู่/โทรศัพท์/เว็บไซต์กับรายการใน PS Locator
4. หากไม่ตรงกัน ให้ยึดข้อมูลจากหน้าทางการเป็นหลัก แล้วแจ้งผู้ดูแลเว็บไซต์
