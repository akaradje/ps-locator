# Changelog

## v1.1.0 — 16 พฤศจิกายน 2569 · ยกระดับ UX/UI

### เพิ่ม
- **คำแนะนำค้นหาแบบทันที (live suggestions)** ขณะพิมพ์ในช่องค้นหาหลัก — จัดอันดับตาม ชื่อสถานี → จังหวัด → ที่อยู่ → โทรศัพท์, เน้นคำที่ตรงด้วยไฮไลต์สีทอง, เลือกด้วยเมาส์หรือปุ่ม ↑ ↓ Enter, Esc ปิด, มีปุ่ม “ดูผลลัพธ์ทั้งหมด”
- **ตัวกรองจังหวัดแบบ combobox ค้นหาได้** แทน dropdown เดิม — พิมพ์ชื่อจังหวัดเพื่อกรองรายชื่อ พร้อมจำนวนสถานีรายจังหวัด, เลื่อนด้วยคีย์บอร์ด, ปิดเมื่อคลิกนอกกล่อง
- **โหมดมืด (dark mode)** สลับด้วยปุ่มบนหัวเว็บ, จำค่าไว้ใน localStorage, เคารพ prefers-color-scheme ของระบบเมื่อผู้ใช้ยังไม่เคยเลือก, ปรับ theme-color ของเบราว์เซอร์ตามธีม
- **ช่องค้นหาด่วนบนหัวเว็บ (mini-search)** โผล่เมื่อเลื่อนพ้นช่องค้นหาหลัก และซิงค์คำค้นสองทาง — ค้นหาต่อได้ทันทีไม่ต้องเลื่อนกลับ
- **จำนวนสถานีบนชิปกองบัญชาการ** อัปเดตตามตัวกรองปัจจุบัน (คำค้น/จังหวัด/เฉพาะที่บันทึก)
- **ปุ่มกลับขึ้นด้านบน** โผล่เมื่อเลื่อนลึก, เลื่อนนุ่มนวล
- **ผลป้อนกลับทันทีเมื่อกดคัดลอก** ปุ่มเปลี่ยนเป็น “คัดลอกแล้ว” พร้อมสีเขียวชั่วครู่ + toast
- **กับดักโฟกัส (focus trap)** ในหน้าต่างรายละเอียด — Tab วนอยู่ภายในกล่อง, Esc ปิดแล้วคืนโฟกัสจุดเดิม
- **ไฮไลต์คำค้นในการ์ดผลลัพธ์** (ชื่อสถานี/ที่อยู่) และแอนิเมชันการ์ดเข้าแบบไล่ลำดับ (เคารพ reduced-motion)
- ประกาศจำนวนผลลัพธ์สำหรับโปรแกรมอ่านหน้าจอ (sr-only live status)

### ปรับปรุง
- ประสิทธิภาพการค้นหา: สร้างดัชนีข้อความ normalize ล่วงหน้าครั้งเดียวตอนโหลด (ไม่ normalize ซ้ำทุกครั้งที่พิมพ์)
- ระบบสีสองธีมผ่าน CSS variables — แยกโทนพื้นหลัง/พื้นผิว/เส้นขอบ/ตัวอักษร และรักษาแถบเข้ม (topbar, วิธีใช้, footer) ให้คงเดิมในโหมดมืด
- scrollbar ตกแต่งตามโทนเว็บทั้งหน้าและในกล่องเลื่อน (suggest/combobox)
- หน้าต่างรายละเอียดบนมือถือ: ขอบชิดจอและปุ่มท้ายกล่องยืดเต็มแถว กดง่ายขึ้น

### หมายเหตุข้อมูล
- **ไม่มีการเปลี่ยนแปลงข้อมูลสถานี** — ยังเป็นชุดเดิม 1,484 แห่ง ครบ 77 จังหวัด ยืนยันจากสำนักงานตำรวจแห่งชาติ (royalthaipolice.go.th)
- การอ้างอิงแหล่งที่มา, การพิมพ์ A4, CSV, การบันทึกสถานี และ URL params ทำงานเหมือนเดิมทุกประการ

- เว็บไซต์ PS Locator (static, ไม่ต้องมี build) — ค้นหาสถานีตำรวจทั่วประเทศ
- ข้อมูลสถานี **1,484 แห่ง ครบ 77 จังหวัด** จากสำนักงานตำรวจแห่งชาติ (royalthaipolice.go.th → “ข้อมูลสถานีตำรวจ”) รวบรวม ณ 16 พ.ย. 2569 — รายการทุกแห่งยืนยันจากต้นทาง
- ผูกภาค/กองบัญชาการให้อัตโนมัติ บช.น. (88 สน.) + ภ.1–ภ.9 (สภ. ภูธร) ตามการแบ่งเขตพื้นที่การปกครองของ ตร.
- ค้นหาแบบยืดหยุ่น (ชื่อ/จังหวัด/ที่อยู่/โทรศัพท์/ภาค) + กรอง บช.น./ภ.1–ภ.9 + เรียงลำดับ
- การ์ดรายละเอียด: ที่อยู่ · โทรศัพท์ (กดโทร) · โทรสาร · เว็บไซต์ทางการ · แผนที่ Google Maps (embed + ปุ่มนำทาง)
- พิมพ์รายละเอียดรายสถานี / พิมพ์บัญชีรายนามตามตัวกรอง (A4, แบบฟอร์มแนบเอกสารคดี พร้อมช่องลงชื่อ)
- ดาวน์โหลด CSV (UTF-8 + BOM) · บันทึกสถานีที่ใช้บ่อย (localStorage) · แชร์ลิงก์พร้อมตัวกรอง (URL params)
- ธีมมินิมอลราชการสมัยใหม่, Responsive มือถือ, คำสั่งลัด `/` เพื่อค้นหา, Esc ปิดหน้าต่าง
